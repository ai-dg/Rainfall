# Rainfall

An introduction to binary exploitation on ELF binaries: twelve progressive setuid levels, each a program with a deliberate vulnerability to exploit in order to read the next level's password.

> Built with [Pierina Camarena](https://github.com/pierinacamarena).

The techniques covered:



Stackoverflow
Heap overflow
Bufferoverflow
GOT
Format string
Saved EIP
EBP
ESP
Canary
EAX
